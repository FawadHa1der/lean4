# The JavaScript export contract (patch 0039): every name a host's JavaScript calls, and nothing
# else. Lean's own native code is NOT exported for the interpreter: it finds boxed wrappers,
# module initializers, constant cells and @[export] functions through a table linked into the
# module (wasm64-build/gen-exports.py --symtab, src/library/wasm_symtab.cpp). gen-exports.py
# copies these names into src/emscripten-exports.txt (-sEXPORTED_FUNCTIONS) and drops, loudly,
# one no source file defines any more. With ERROR_ON_UNDEFINED_SYMBOLS=0 a name that is not
# defined silently disappears from the link: the gate's S2 check binds every name here.
# One name per line, `# who calls it` after it. W = QED64 public/workers/lean.worker.js (also
# lean4game's served copy), snap/persistent/resident/storm = QED64 pipeline/snapshot/*-probe.mjs,
# kernel js = this repository's wasm64-build/js tools. Before removing a name, run
# wasm64-build/js/exports-audit.mjs over every consumer (EMBED-RUNTIME.md §2 lists the [RT] ones).
